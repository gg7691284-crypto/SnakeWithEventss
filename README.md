# Snake With Events

Консольная змейка для трёх участников учебной команды. Написана на C++17 и запускается без дополнительных библиотек.

## Как запустить

Нужен компилятор C++17. В CLion можно открыть папку как проект CMake и запустить цель `snake`.

В PowerShell с MinGW/GCC:

```powershell
g++ -std=c++17 -Wall -Wextra snake.cpp -o snake.exe
.\snake.exe
```

В Linux или macOS с GCC или Clang:

```bash
c++ -std=c++17 -Wall -Wextra snake.cpp -o snake
./snake
```

Чтобы показать обе механики на защите, запустите `snake --demo` (в PowerShell `.\snake.exe --demo`). Режим печатает четыре кадра одной заранее заданной партии.

## Правила

- Введите `W`, `A`, `S` или `D` и нажмите Enter. Пустой Enter продолжает движение прямо. Разворот на 180° игнорируется.
- Еда `@` даёт **10 очков** и удлиняет змейку. Столкновение со стеной, собственным телом или камнем завершает раунд. Если змейка занимает всё поле, это победа.
- `Q` завершает игру. После проигрыша или победы `R` начинает новый раунд.

| Событие | Когда | Что меняется |
| --- | --- | --- |
| Золотое яблоко `*` | Ходы 6, 18, 30 и далее | Даёт 30 очков без роста. Доступно следующие 4 хода или до сбора. |
| Камнепад `X` | Ходы 12, 24, 36 и далее | До трёх препятствий на свободных клетках на следующие 4 хода. |

## Проверка

При сборке CMake доступны тесты правил и демонстрационного запуска. После сборки выполните `ctest --test-dir build --output-on-failure`, если папка сборки называется `build`.
